
# EC9180 – Electrical Installation Design
## Group 02 | University of Jaffna

### Project Overview

This project focuses on the **electrical installation design for the Mechanical Engineering Workshop at the University of Jaffna**. It covers the planning and design of an electrical installation system, incorporating electrical load considerations, rooftop solar photovoltaic (PV) system design, and lightning protection.

The project applies electrical engineering principles to develop a practical and systematic design suitable for a university workshop environment.

### Project Objectives

- Design an appropriate electrical installation for the Mechanical Engineering Workshop.
- Analyze electrical loads and installation requirements.
- Incorporate a rooftop solar photovoltaic (PV) system into the design.
- Develop a suitable lightning protection system.
- Apply electrical engineering concepts to a practical engineering facility.

### Project Scope

- **Electrical Installation Design** – Electrical load assessment and installation planning.
- **Solar PV System Design** – Rooftop solar photovoltaic system planning.
- **Lightning Protection Design** – Protection against lightning-related hazards.
- **Technical Documentation** – Project report, design drawings, calculations, and supporting files.
